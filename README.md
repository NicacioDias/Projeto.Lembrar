PRD — 💊 Lembrei do Remédio
1. Visão geral do produto

Nome: Lembrei do Remédio
Tipo: Aplicativo mobile de lembretes de medicamentos.

Descrição:

O “Lembrei do Remédio” é um aplicativo simples que ajuda usuários a lembrar de tomar seus medicamentos nos horários corretos. O aplicativo permite cadastrar medicamentos, definir horários e receber notificações para evitar esquecimentos.

2. Problema

Muitas pessoas esquecem de tomar seus medicamentos no horário correto, principalmente idosos e pessoas que utilizam medicamentos diariamente.

O esquecimento pode prejudicar o tratamento e causar problemas à saúde.

Problema principal:

 “Como ajudar as pessoas a lembrarem de tomar seus medicamentos nos horários determinados?”


3. Objetivo do produto

Criar um aplicativo simples, fácil de usar e acessível que permita ao usuário:

Cadastrar seus medicamentos.
Definir os horários.
Receber lembretes.
Marcar o medicamento como tomado.
Acompanhar os medicamentos que já foram tomados.

4. Público-alvo

Público principal:

Idosos.
Pessoas com doenças crônicas.
Pessoas que tomam medicamentos diariamente.
Pessoas que possuem vários medicamentos.

Público secundário:

Familiares e cuidadores que ajudam outras pessoas a controlar seus medicamentos.

5. Funcionalidades principais

💊 1. Cadastro de medicamento
O usuário poderá cadastrar:

Nome do medicamento.
Dosagem.
Horário.
Frequência de uso.
Observações opcionais.

⏰ 2. Definição de horário
O usuário poderá escolher o horário em que deverá tomar o medicamento.

Exemplo:

  Remédio: Losartana
  Dosagem: 50 mg
  Horário: 08:00

🔔 3. Notificação
O aplicativo enviará uma notificação no horário programado.

Exemplo:

  🔔 Hora do medicamento!
  Está na hora de tomar sua Losartana 50 mg.

✅ 4. Marcar como tomado

O usuário poderá tocar em “Tomei” para registrar que tomou o medicamento.

Também poderá existir a opção:
      “Lembrar depois”

📋 5. Lista de medicamentos

O usuário poderá visualizar todos os medicamentos cadastrados e seus próximos horários.

6. Fluxo principal do usuário

Abrir aplicativo
↓
Cadastrar medicamento
↓
Definir horário
↓
Receber notificação
↓
Tomar medicamento
↓
Clicar em “Tomei”
↓
Registro atualizado

7. Requisitos funcionais

O sistema deve permitir cadastrar medicamentos.
O sistema deve permitir definir horários.
O sistema deve enviar notificações nos horários definidos.
O sistema deve permitir marcar o medicamento como tomado.
O sistema deve exibir os medicamentos cadastrados.
O sistema deve permitir editar ou excluir medicamentos.
O sistema deve registrar os medicamentos tomados.

8. Requisitos não funcionais

Interface simples e intuitiva.
Letras grandes para facilitar a leitura.
Botões grandes e fáceis de tocar.
Aplicativo rápido.
Notificações confiáveis.
Dados do usuário protegidos.
Compatibilidade com celulares Android e, futuramente, iOS.

9.  Primeira versão

Para manter o projeto pequeno, a primeira versão terá somente:

Essencial:

Cadastro de medicamento.
Definição de horário.
Notificações.
Botão “Tomei”.
Lista de medicamentos.
Editar/excluir medicamento.

Futuras versões:

Histórico de medicamentos.
Relatórios.
Aviso para familiares/cuidadores.
Controle de estoque de medicamentos.
Lembrete para comprar mais medicamentos.
Integração com smartwatch.

10. Métricas de sucesso

O aplicativo poderá ser considerado bem-sucedido se:

Os usuários cadastrarem seus medicamentos.
A maioria das notificações foi visualizada.
Os usuários marcarem os medicamentos como tomados.
Houve poucos abandonos do aplicativo.
Os usuários relataram que esqueceram menos medicamentos.

11. Resultado esperado

O “Lembrei do Remédio” deve ser um aplicativo simples, acessível e confiável, ajudando principalmente idosos e pacientes que precisam tomar medicamentos regularmente a manterem sua rotina de tratamento organizada.

Objetivo principal:

 “ Ajudar o usuário a não esquecer seus.     medicamentos.”
